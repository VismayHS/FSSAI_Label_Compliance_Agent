# Incident log (D8)

One file per real incident, named `YYYY-MM-DD-<name>-<slug>.md`. Each covers what happened, how it was noticed,
the cause, the fix and the lesson (LLM_Context §8.7). Every team member writes at least one. Only real incidents
belong here: an entry for something that did not happen is worse than none. The runbook
([`../runbook.md`](../runbook.md)) is built from these entries.
